## Problem 1

+++ {"editable": true, "slideshow": {"slide_type": ""}}

Fit polynomial of the second degree to the data. Use the `curve_fit` function from  `scipy.optimize`. Calculate the mean squared error (MSE).

```{code-cell} ipython3
---
editable: true
slideshow:
  slide_type: ''
---
def quad_poly(x, a, b, c):
    return a * x**2 + b * x + c

popt, pcov = curve_fit(quad_poly, x_data, y_data)
a_cf, b_cf, c_cf = popt
print(f"curve_fit: a={a_cf:.4f}, b={b_cf:.4f}, c={c_cf:.4f}")

y_pred_cf = quad_poly(x_data, *popt)
mse_cf = np.mean((y_pred_cf - y_data)**2)
print(f"MSE (curve_fit): {mse_cf:.4f}")

x_plot = np.linspace(0, 2, 200)
fig, ax = plt.subplots(figsize=(8, 5))
ax.scatter(x_data, y_data, label='Data', alpha=0.7, zorder=5)
ax.plot(x_plot, quad_poly(x_plot, *popt), color='red',
        label=f'Fit: {a_cf:.2f}x² + {b_cf:.2f}x + {c_cf:.2f}')
ax.set_xlabel('x')
ax.set_ylabel('y')
ax.set_title('Quadratic Fit (curve_fit)')
ax.legend()
plt.show()
```

## Problem 2 - Bayesian fit

+++ {"editable": true, "slideshow": {"slide_type": ""}}

Construct a PyMC model for the quadratic polynomial to fit to the data. Treat the $\sigma$ as an another parameter. Use the $\frac{1}{\sigma}$ prior. Use wide Gaussian priors for the polynomial coefficients.

```{code-cell} ipython3
---
editable: true
slideshow:
  slide_type: ''
---
with pm.Model() as model_quad:
    # 1/sigma prior: p(sigma) ∝ 1/sigma  ↔  log_sigma ~ Flat
    log_sigma = pm.Flat('log_sigma')
    sigma = pm.Deterministic('sigma', pm.math.exp(log_sigma))

    a = pm.Normal('a', mu=0, sigma=10)
    b = pm.Normal('b', mu=0, sigma=10)
    c = pm.Normal('c', mu=0, sigma=10)

    mu = a * x_data**2 + b * x_data + c
    obs = pm.Normal('obs', mu=mu, sigma=sigma, observed=y_data)
```

a_samples = trace_quad.posterior['a'].values.flatten()
b_samples = trace_quad.posterior['b'].values.flatten()
c_samples = trace_quad.posterior['c'].values.flatten()

y_samples = a_samples[:, None] * x_test**2 + b_samples[:, None] * x_test + c_samples[:, None]

y_mean = y_samples.mean(axis=0)
y_std  = y_samples.std(axis=0)

fig, ax = plt.subplots(figsize=(8, 5))
ax.scatter(x_data, y_data, label='Data', alpha=0.7, zorder=5)

                alpha=0.3, color='red', label='±1 std')
